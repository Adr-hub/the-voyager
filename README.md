# The Voyager (French version)
Une petite histoire de voyage dans le temps que j'ai développée uniquement avec Bitsy (https://www.bitsy.org/). J'espère que vous apprécierez !
## Comment jouer ?
Il vous faut un ordinateur :D Ensuite, cliquez sur Espace ou sur la flèche du bas pour dérouler les différents dialogues du jeu. Pour vous déplacer, vous pouvez utiliser les flèches directionnelles de votre clavier. Si vous perdez le contrôle du protagoniste, cliquez tout simplement sur la fenêtre du jeu avec votre souris ou votre pavé tactile.
### Une précision !
Le jeu est insonore.
